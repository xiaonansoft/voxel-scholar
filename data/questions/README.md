# 题库

| 目录 | 谁用 | 标记 |
| --- | --- | --- |
| `demo/` | `npm run build` 的默认公开包 | `ORIGINAL`，方块备考自编示范题 |
| `extracted/` | `npm run build:extracted`，产物在 `dist/personal/` | 全部 `NEED_REWRITE`，从原型拆出，不是已获教材授权的文本 |

开源题库需要自编。抽出的题可以在自己电脑上打开来重写，不要把它当成可以公开分发的课文。

分组甲 / 分组乙对应原型里的两套单元槽位。示范构建会把单元标题换成练习名称；提取构建仍保留原型里的单元标题，方便你知道原来的槽位，那些标题同样不代表教材授权。
